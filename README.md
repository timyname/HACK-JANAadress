# Jana Address

Проект команды №73 для кейса Jana Post на Terricon Hackathon 2026.

Jana Address превращает адрес в свободной форме в 14 структурированных полей. Сервис работает локально, использует справочник КАТО и OpenStreetMap и не отправляет адреса во внешний геокодер.

## Что умеет прототип

- разбирает адреса на русском и казахском языках;
- сохраняет исходную строку и порядок записей;
- находит город, район, улицу, дом, квартиру, подъезд и этаж;
- исправляет опечатки в названиях улиц с помощью RapidFuzz;
- определяет район по точной паре «улица + дом»;
- показывает источник каждого поля в интерфейсе;
- сохраняет ручные правки отдельно от исходного результата;
- принимает до 10 000 записей через HTTP API;
- обрабатывает крупные локальные файлы в потоковом NDJSON-режиме.

## Пример

Вход:

```text
Астана манглик ел 47 квартира 57
```

Основные поля результата:

```json
{
  "city": "Астана",
  "district": "Есиль",
  "street_type": "проспект",
  "street_name": "Мангилик Ел",
  "house": "47",
  "apartment": "57"
}
```

RapidFuzz сравнивает строку только с улицами уже найденного города. Минимальный порог сходства составляет 80%. Если два варианта имеют близкие оценки, сервис не выбирает улицу автоматически. Район добавляется только после проверки дома в локальном справочнике.

## Быстрый запуск

Для полного запуска нужен файл `data/public/gazetteer.sqlite`. Он входит в локальный конкурсный пакет, но не хранится в GitHub из-за размера.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONPATH=backend .venv/bin/python -m uvicorn jana.api:app --host 127.0.0.1 --port 8080 --no-access-log
```

После запуска откройте [http://127.0.0.1:8080](http://127.0.0.1:8080).

Запуск через Docker:

```sh
docker compose build
docker compose up -d
curl http://127.0.0.1:8080/health/ready
```

## API

Основной маршрут: `POST /parse`.

```sh
curl -X POST http://127.0.0.1:8080/parse \
  -H "Content-Type: application/json" \
  --data '[{"id":"demo-1","raw_address":"Астана манглик ел 47 квартира 57"}]'
```

Сервис также поддерживает `POST /batch`, `POST /api/parse` и `POST /api/v1/parse`.

## Проверка

```sh
PYTHONPATH=backend python -m pytest -q
node --test site/tests/*.test.mjs
node scripts/build-site.mjs
```

Текущий результат проверки: 681 Python-тест, 255 подтестов и 36 JavaScript-тестов прошли успешно.

## Структура

- `backend/jana/` — API, парсер и работа со справочником;
- `site/` — интерфейс оператора;
- `tools/` — сборка справочника, проверка и измерения;
- `tests/` — автоматические тесты;
- `configs/` — настройки синтетического корпуса;
- `data/public/` — сведения об открытых источниках;
- `docs/` — сценарий демонстрации и контракт данных;
- `presentation/` — презентация команды №73.

## Данные

Географический справочник строится из открытых данных КАТО БНС РК и OpenStreetMap/Geofabrik. Сведения об источниках и лицензиях находятся в `data/public/ATTRIBUTION.md` и `data/public/source-manifest.json`.

Демо использует синтетические адреса. Реальные клиентские данные в репозиторий не включены.
