# Jana Address: сценарий защиты на 3 минуты

## Перед началом

- Вписать номер команды на первом слайде и в названии отправляемого сообщения.
- Открыть презентацию, локальный интерфейс `http://127.0.0.1:8080` и папку для сохранения результата.
- В Zoom заранее выбрать показ нужного экрана и отключить уведомления.
- Проверить, что интерфейс показывает статус готовности сервера.

## Ответы на вероятные вопросы

**Почему офлайн?** Адреса могут содержать чувствительные данные. Runtime не обращается к внешнему геокодеру, а справочник хранится локально.

**Откуда география?** Используются открытые КАТО БНС РК и OpenStreetMap/Geofabrik. Источники, версии и контрольные суммы зафиксированы в manifest.

**Что означает 95,1%?** Это точность по отдельным полям на синтетическом наборе из 1 000 адресов. Полное совпадение всей записи составляет 65,9%. Скрытая выборка жюри может дать другой результат.

**Как обрабатываются большие файлы?** HTTP API принимает до 10 000 записей. Для более крупных локальных выгрузок есть потоковый NDJSON-режим с пакетной обработкой и атомарной публикацией результата.

**Можно ли исправлять результат?** Да. Интерфейс сохраняет правки оператора отдельно и экспортирует отдельную версию «С правками».

**Как исправляются опечатки в улицах?** После определения города RapidFuzz сравнивает строку с названиями улиц этого города. Минимальный порог составляет 80 процентов. Если два варианта близки по оценке, сервис не выбирает улицу автоматически.

**Как определяется район?** После выбора улицы сервис ищет точную пару «улица + дом» в локальном справочнике. Для примера «Мангилик Ел, 47» справочник возвращает район Есиль.

**Что уже проверено?** API, интерфейс, локальный SQLite-справочник, Docker-запуск, тесты и обработка 1 000 адресов с измеренным временем.

## План B

- Если live demo не открылось за 10 секунд, показать третий слайд со скриншотами и проговорить тот же маршрут.
- Не показывать реальные или закрытые адреса. Использовать только демо-пакет.
- Не запускать сборку справочника во время защиты. Показывать готовый runtime.
